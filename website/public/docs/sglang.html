SGLang integration

SGLang is a fast inference engine for LLMs and vision-language models. RavenClaws supports SGLang as a first-class provider (provider = "sglang", default endpoint http://localhost:30000), or via the generic openai-compatible provider.

Quick start

1. Start SGLang server

Using Docker (recommended):

shell
docker run --rm --gpus all -p 30000:30000 \
  lmsysorg/sglang:latest \
  python3 -m sglang.launch_server \
  --model-path Qwen/Qwen2.5-7B-Instruct \
  --port 30000

Or using pip:

shell
pip install "sglang[all]"
python -m sglang.launch_server \
  --model-path Qwen/Qwen2.5-7B-Instruct \
  --port 30000

2. Configure RavenClaws

Via environment variables:

shell
export RAVENCLAWS__LLM__PROVIDER="sglang"
export RAVENCLAWS__LLM__MODEL="Qwen/Qwen2.5-7B-Instruct"

ravenclaws --exec "What is the capital of France?"

Configuration reference

FieldValueDescription
providersglangFirst-class provider (or openai-compatible)
endpointhttp://localhost:30000SGLang's OpenAI-compatible endpoint (default)
model(model name)The model loaded in SGLang
api_key(optional)Not needed for local SGLang

Tool-calling support

BackendTool callingNotes
SGLang (with tool support)✅ StructuredWorks with models that support OpenAI tool format
SGLang (no tool support)⚠️ Text fallbackRavenClaws detects TOOL_CALL: / ARGS: patterns

SGLang serves an OpenAI-compatible API, so tool calling works identically to the openai-compatible provider.

Multi-model with SGLang

You can use SGLang alongside other providers in multi-model mode:

ravenclaws.toml
[[llms]]
provider = "sglang"
endpoint = "http://localhost:30000"
model = "Qwen/Qwen2.5-7B-Instruct"

[[llms]]
provider = "vllm"
endpoint = "http://localhost:8000"
model = "mistralai/Mistral-7B-Instruct-v0.3"
